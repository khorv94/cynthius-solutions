### Job Description

We are looking for a skilled and detail-oriented Web Developer to join our web design agency team. In this role, you will be responsible for building fast, scalable, and modern websites using JAMstack architecture and static site generation technologies. You will collaborate closely with designers, project managers, and marketing specialists to develop high-performing websites that deliver exceptional user experiences and reliable performance.

The ideal candidate has strong technical expertise, experience working with headless CMS platforms, and a passion for clean, efficient code and modern web development workflows.

##### Responsibilities:

* Develop and maintain responsive, high-performance websites using JAMstack technologies;

* Build and manage static websites using Hugo and other static site generators;

* Integrate and manage headless CMS platforms for dynamic content management;

* Collaborate with designers to accurately implement UI/UX designs and interactive features;

* Optimize websites for speed, SEO, accessibility, and security;

* Set up and maintain Git-based workflows, repositories, and version control processes;

* Configure and manage CI/CD pipelines using GitHub Actions and related deployment tools;

* Troubleshoot website issues, bugs, and performance bottlenecks;

* Work closely with project managers and team members to meet project timelines and technical requirements;

* Stay updated on emerging web technologies, JAMstack best practices, and development trends;

##### Requirements:

* Proven experience as a Web Developer or similar role;

* Strong proficiency with JAMstack architecture and modern frontend development workflows;

* Experience with Hugo and static site generation technologies;

* Strong understanding of headless CMS platforms such as Contentful, Sanity, Strapi, Directus, or similar tools;

* Proficiency with Git, GitHub, and collaborative version control practices;

* Experience configuring and maintaining GitHub Actions or other CI/CD automation tools;

* Strong knowledge of HTML, CSS, JavaScript, and responsive web development;

* Familiarity with API integrations and modern deployment platforms such as Netlify, Vercel, or Cloudflare Pages;

* Understanding of web performance optimization, SEO best practices, and accessibility standards;

* Strong problem-solving, communication, and organizational skills;
